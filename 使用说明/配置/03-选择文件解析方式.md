# 选择文件解析方式

进入 **设置 → 组件设置**，选择默认文件解析方式，修改后点击 **保存**。

![文件解析配置](../images/标注/05-文件解析配置.png)

## 文件解析

| 方式 | 适用情况 | 配置要求 |
| --- | --- | --- |
| 本地解析 | 普通 Word、Excel、WPS、Markdown 和带文字层的 PDF | 无需 Token，不支持扫描件文字识别 |
| MinerU-精准解析 API | 扫描件，或本地解析效果不满足需要的文件 | 填写 MinerU Token；页面标示单文件不超过 200MB、200 页 |
| MinerU-Agent 轻量解析 API | 小文件的备用解析 | 无需 Token，但有 IP 限频；页面标示不超过 10MB、20 页 |

Excel 文件在两种 MinerU 方式下仍使用本地解析。选择后重新导入需要处理的文件，并检查解析出的正文是否完整。

## 本地转图

组件设置中可以分别设置 Mermaid 图和 HTML 图表的本地转换并发量，默认均为 5。并发量越高，同时占用的本机资源越多。

技术方案中的这两类配图会先转换为图片，再用于正文和 Word 导出。普通 Markdown 中的 Mermaid 代码块只作为代码显示。
