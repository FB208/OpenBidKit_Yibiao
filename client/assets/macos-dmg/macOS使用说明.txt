macOS 使用说明

如果双击 App 提示“已损坏，无法打开”或“无法验证开发者”，这是因为本软件未进行 Apple 官方签名和公证，并不代表文件真的损坏。

macOS 未签名版本安装说明

1. 打开 DMG，将“易标投标工具箱.app”拖入“应用程序”。
2. 打开终端，执行下面命令解除 macOS quarantine：

   xattr -dr com.apple.quarantine "/Applications/易标投标工具箱.app"

3. 再从“应用程序”中打开“易标投标工具箱”。

说明：
- 这个命令会递归处理整个 .app，包括 Pi Agent 使用的内置命令工具。
- Pi Agent 已内置，不需要用户额外安装智能体运行时。
- 正常情况下不需要手动 chmod，程序包已经在构建阶段设置好可执行权限。
- 如果开启开发者模式后运行 Pi Agent 链路测试页，提示 spawn EACCES，再按机器架构执行对应命令排查：

  chmod +x "/Applications/易标投标工具箱.app/Contents/Resources/agent-tools/darwin-arm64/bin/"*
  chmod +x "/Applications/易标投标工具箱.app/Contents/Resources/agent-tools/darwin-x64/bin/"*

  Apple Silicon 机器通常使用 darwin-arm64；Intel 机器通常使用 darwin-x64。
