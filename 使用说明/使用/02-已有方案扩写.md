# 已有方案扩写

在左侧点击 **内容生成 → 标书生成**。

1. 在“选择标书”上传招标文件。
2. 进入“生成设置”，打开“我有方案”，上传已经写好的技术方案并选择原方案目录处理方式：

- **仅使用原方案目录**：保持原目录结构。
- **AI基于原方案补充**：在原目录基础上补充招标文件要求但原方案缺少的内容。

3. 在“写嘛”中选择“完整投标文件”“技术文件独立成册”或“商务标独立成册”。
4. 如需引用知识库内容，在“知识库”中选择参考文档。
5. 如需控制篇幅和表格数量，在“写多少”中完成设置；在“插图吗”中选择 AI、Mermaid 和 HTML 配图方式，并在“怎么写”中选择不确定信息的统一写法。配置修改后会自动保存并提示“保存成功”。完成招标文件解析后进入目录生成并直接启动任务。

后续按“目录 → 全局事实 → 正文 → 导出 Word”的顺序操作。软件会保留原方案已有正文，并为缺失或需要扩充的部分生成内容。

是否启用已有方案优化扩写只取决于“我有方案”中是否存在已上传文件。上传、替换或移除原方案不会清空已有目录、全局事实、正文、生成进度和配图结果；后续重新生成时使用当前原方案。
